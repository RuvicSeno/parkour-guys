# Assets Folder Structure

Place your custom game assets into the respective subdirectories below:

- `assets/audio/sfx/` -> Sound effects (.wav or .ogg format, e.g. `jump.wav`, `checkpoint.wav`, `win.wav`, `fall.wav`)
- `assets/audio/music/` -> Background music (.ogg or .mp3 format, e.g. `bgm.ogg`)
- `assets/models/` -> 3D character or obstacle models (.gltf, .glb, or .obj format)
- `assets/textures/` -> Texture images (.png or .jpg format)
- `assets/animations/` -> Character animations or rig files (.gltf, .glb)
- `assets/ui/` -> UI icons, banners, fonts, or custom logo images (.png, .ttf, .otf)

Once you drop your assets in these folders, let me know in your next prompt which assets you'd like applied!
